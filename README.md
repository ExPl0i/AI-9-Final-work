## Итоговая практическая работа по Теме 1 (ПР №4 и ПР №5)

Итоговое занятие Темы 1 курса «Искусственный интеллект» для 9 класса. Ученики проходят полный цикл решения задачи машинного обучения на новом наборе данных: по показаниям датчиков беспилотного автомобиля определяют тип дорожного покрытия. Нужно осмотреть и очистить данные, найти в них ловушки, разделить выборку, изучить данные методами обучения без учителя, выбрать модель и гиперпараметры кросс-валидацией, один раз проверить модель на тестовой выборке и написать отчет. В этой работе впервые разрешено полноценно пользоваться библиотеками `pandas` и `scikit-learn`. Защита работы засчитывается как промежуточный контроль по Теме 1.

## Теория (презентация)

1. **Полный цикл решения задачи.** Что мы умеем после одиннадцати занятий Темы 1. Восемь шагов от задачи до отчета. Чек-лист из семи типичных ловушек: признак «из будущего», подготовка данных до разбиения, выбор модели по тестовой выборке, точность при несбалансированных классах, отсутствие модели-ориентира, разный масштаб признаков, служебные номера в признаках. Выбор метрики под задачу: не все ошибки одинаково дорогие.
2. **От своих функций к scikit-learn.** Единый интерфейс методов `fit`, `transform`, `predict`. Конвейер `Pipeline`, разная подготовка числовых и категориальных признаков в `ColumnTransformer`, подбор гиперпараметров `GridSearchCV` со стратифицированными блоками. Основные команды `pandas` для работы с таблицей.
3. **Задание.** Тип дорожного покрытия по датчикам автомобиля, предупреждение о ловушках в данных, план работы, критерии оценивания, формат защиты.

## Практическая работа

Классы: сухой асфальт, мокрый асфальт, грунт, снег и лед. Около 1000 строк и 16 признаков: вибрация подвески, скорость и проскальзывание колес, температура воздуха и дороги, влажность, интенсивность отражения лидара, яркость кадра камеры, шум в салоне и другие. У каждого ученика свой вариант данных. Номер варианта указывается в первой ячейке ноутбука.

| Часть | Шаг | Что делаем |
| --- | --- | --- |
| ПР №4 | 1 | первый взгляд на данные: размер, типы признаков, доли классов |
| | 2 | пропуски, дубликаты, невозможные значения, разнобой в записи; функция очистки |
| | 3 | разбор признаков, поиск ловушки, стратифицированное разбиение на обучающую и тестовую выборки |
| | 4 | разведка на обучающей выборке: средние по классам, распределения, корреляции |
| | 5 | метод главных компонент, метод k средних, коэффициент силуэта и скорректированный индекс Рэнда |
| ПР №5 | 6 | выбор метрики (F-мера с макроусреднением, полнота класса «снег и лед»), модель-ориентир |
| | 7 | конвейер подготовки данных и модели, проверка влияния стандартизации |
| | 8 | подбор гиперпараметров для метода k ближайших соседей, логистической регрессии, дерева решений и метода соседей после метода главных компонент |
| | 9 | однократная проверка лучшей модели на тестовой выборке, матрица ошибок, разбор опасных ошибок |
| | 10 | отчет |

Каждая практическая работа оценивается из 10 баллов, критерии приведены в начале ноутбука.

Задания повышенной сложности: увеличение веса опасного класса, новые признаки на основе физики, кривая обучения, случайный лес, собственный метод k ближайших соседей внутри конвейера `scikit-learn`.
